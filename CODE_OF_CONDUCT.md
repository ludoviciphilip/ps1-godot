# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the project. Harassment,
personal attacks, and discriminatory language or behavior are not welcome.

## Reporting

If you experience or witness unacceptable behavior in this repository (issues, pull requests,
discussions), report it by opening a private security advisory
(see [SECURITY.md](SECURITY.md) for the link) or by contacting the maintainer,
[@ludoviciphilip](https://github.com/ludoviciphilip), directly.

All reports will be reviewed and handled with discretion.

For the full text of the Contributor Covenant, see
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
